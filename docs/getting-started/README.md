# Getting started

Start with the root [Quick Start](../../README.md#quick-start--installation), then
use the [CLI reference](../reference/README.md) for exact command behavior.

Follow [Installation and first context](installation.md) for supported private
installation paths, prerequisites, the first doctor/scan/pack/context workflow,
cross-platform notes, and cleanup.

Fuzit is local-first: repository content remains on the local machine unless the
user explicitly invokes a separately configured integration. Product workflow
requirements are owned by the [normative specification index](../../specs/README.md).
