# Fuzit v0.0.1 repair ledger

This ledger groups the public Windows audit symptoms by source-level root cause. It is an internal repair record, not release notes.

| ID | Severity | Surface | Reproduction / observed behavior | Expected behavior | Root cause | Source / regression coverage | Resolution |
| --- | --- | --- | --- | --- | --- | --- | --- |
| FZR-001 | High | `scan` | Run bare `fuzit scan`; v0.0.1 exits with `SCAN.MODE_REQUIRED` and internal “baseline” wording. | Bare scan returns a useful repository summary. | The command dispatcher treated every scan mode as opt-in. | `apps/cli/src/commands/scan/register.ts`; `apps/cli/test/scan.test.ts` | Fixed: bare scan uses summary mode while explicit modes remain available. |
| FZR-002 | Medium | Classification | Scan `.gitignore`, JSX, and CSS; `.gitignore` may be marked generated and mainstream extensions are `Unknown`. | Stable mainstream language metadata and no false generated classification. | Narrow extension map and an unanchored content heuristic. | `packages/scanner/src/classification/classify-file.ts`; classifier tests | Fixed: expanded mainstream formats and excluded `.gitignore` from generated-header matching. |

| FZR-014 | Medium | VS Code | Extension was not installed in the audit environment, leaving activation/package behavior unproven there. | Packaged extension activates and handles workspace modes/errors. | Environment/coverage gap. | VS Code tests and package smoke | Pending final validation; no extension source change planned unless tests expose a shared-functionality defect. |

## Root-cause groups

1. Command contracts exposed implementation prerequisites instead of user workflows (`scan`, graph).
2. Retrieval scoring rewarded volume instead of evidence quality (context).
3. Remote runners parsed identifiers but performed no acquisition (PR and issue).
4. Output routing lacked an activity concept (long-running CLI operations).
5. User JSON parsing and plugin discovery treated common Windows input and parse failures unsafely (BOM and swallowed diagnostics).
6. Several surfaces were coverage gaps rather than confirmed defects (snapshot edge cases, complete MCP/VS Code/package clean-room paths).
